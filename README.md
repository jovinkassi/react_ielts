--- IELTS Pro – Made with React & Tailwind ---

A modern, responsive Home Page for a fictional IELTS Institute.

## Features

- Responsive Navbar, Hero banner, Feature cards,Student testimonials,Footer
- Built with React + Tailwind CSS

## Setup

1. Clone repo: `git clone https://github.com/jovinkassi/react_ielts.git`
2. Install dependencies: `npm install`
3. Run project: `npm start`

## Design Choices

- Tailwind CSS: More better styling options
- Minimal layout: Feature cards and Testimonial cards made small so that the page looks clean and visible
- Consistent colors: Blue & white for professional and futuristic feel
- Mobile-first: Navbar collapses into menu and the grid size reduces or collapses
